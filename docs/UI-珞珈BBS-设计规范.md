## 0. 设计总览

### 0.1 一句话设计立意

> **珞珈绿为骨，樱花粉为神，暖纸为底，鎏金为信。** —— 让同学在打开 App 的第一秒，就认出「这是武大人自己的社区」。

珞珈BBS 的「高级感」不来自炫技，而来自**克制的秩序**（呼应 PRD 的「有序优先 / 克制」原则）：干净的暖纸底色、深沉的珞珈绿、克制的樱花粉点缀、留白与字体层级带来的呼吸感。视觉上做减法，功能上做秩序，情绪上用一点点樱花粉让人愉悦。

### 0.2 四个设计关键词

| 关键词 | 视觉落地 |
| --- | --- |
| **归属感** | 珞珈绿 × 樱花粉的品牌色，一眼武大 |
| **秩序** | 卡片留白、清晰层级、标签与状态标识的克制使用 |
| **可信** | 「武大学生」鎏金徽标、克制的认证标识，不堆砌 |
| **愉悦** | 樱花粉用于点赞、收藏、空状态等「温暖时刻」，暖纸底色不刺眼 |

### 0.3 设计原则

1. **留白即高级**：卡片间距、行高、内边距服从 8pt 栅格，宁松勿挤。
2. **一屏一主色**：绿色是「行动」色（按钮/链接/选中态），粉色是「情绪」色（点赞/收藏/高亮/空状态），金色是「身份」色（认证徽标）。三种颜色各司其职，不混用。
3. **克制的点缀**：任何页面同时最多出现 2 个强调色，避免「彩虹感」。
4. **暗色等同公民**：暗色不是反色，而是同一套 token 的重新配比，两端必须同时支持。

## 1. 色彩系统

### 1.1 品牌色（三色立意）

| 色 | 灵感来源 | 角色 | 主色值 |
| --- | --- | --- | --- |
| **珞珈绿** | 武大老建筑琉璃绿瓦、珞珈山 | 主色 / 行动色 | `#2C8063` |
| **樱花粉** | 樱花大道 | 情绪色 / 强调色 | `#D44768` |
| **鎏金** | 校徽 / 认证与权威感 | 身份色 / 认证徽标 | `#C29A5B` |

> 三色取义：绿为骨（骨架与品牌）、粉为神（情绪与温度）、金为信（信任与权威）。这正是「高级感 + 归属感」的底色。

### 1.5 中性色 · 暖纸（Neutral，浅色模式）

底色不走纯白/纯灰，而是带 2% 暖调绿意的「暖纸」，配合珞珈绿形成温润的高级感。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `paper` | `#F8F6F1` | 页面背景 |
| `surface` | `#FFFFFF` | 卡片 / 浮层表面 |
| `surface-2` | `#F2EFE8` | 次级表面（输入框、分组底） |
| `line` | `#E7E2D8` | 分隔线 / 描边 |
| `line-strong` | `#D8D2C4` | 强调描边 |

### 1.6 墨色（Ink，文字）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `ink-900` | `#18201B` | 标题 / 正文强调 |
| `ink-700` | `#3B4640` | 正文 |
| `ink-500` | `#66726B` | 次要文字 / 说明 |
| `ink-400` | `#97A09A` | 占位符 / 禁用 |

### 1.7 功能色（克制的语义色）

功能色统一**降低饱和、带暖调**，避免刺眼，与整体高级感一致。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `success` | `#34A26B` | 成功（发布成功、审核通过） |
| `warning` | `#D89B3C` | 警告（内容待审核、即将过期） |
| `error` | `#D65C5C` | 错误 / 危险操作（删除、举报） |
| `info` | `#5B84C4` | 提示 |

### 1.8 暗色模式

暗色模式不是「把浅色反色」，而是**把暖纸换成珞珈绿深底**，让暗色也有品牌归属感。

| Token | 浅色 | 暗色 |
| --- | --- | --- |
| 页面背景 | `#F8F6F1` | `#121614`（深绿黑） |
| 表面 | `#FFFFFF` | `#1A201C` |
| 次级表面 | `#F2EFE8` | `#232B26` |
| 描边 | `#E7E2D8` | `#2E3832` |
| 标题 | `#18201B` | `#EAF0EC` |
| 正文 | `#3B4640` | `#C4CDC7` |
| 次要文字 | `#66726B` | `#99A49D` |
| 主色（行动） | `#2C8063` | `#549E82` |
| 情绪色 | `#D44768` | `#E5738B` |
| 鎏金 | `#C29A5B` | `#D6B36E` |

> 实现方式：统一用 CSS 变量（小程序用 WXSS 变量 + `theme` 类名，Web 用 `:root` / `prefers-color-scheme`），**组件内一律引用 token，禁止写死色值**。

### 1.9 使用规范

- **对比度**：正文文字与背景对比度 ≥ 4.5:1，大标题 ≥ 3:1（WCAG AA）。`ink-500` 仅用于辅助文字，不用于正文。
- **主色使用**：绿色只用于「可点击/被选中/在操作」；非交互文字不染绿。
- **情绪色使用**：粉色只用于「喜欢/收藏激活、高亮提醒、空状态插画、女性化友好的温暖时刻」，不做大面积底。
- **身份色使用**：鎏金只用于「武大学生」认证徽标与官方身份标识，不滥用。

## 2. 字体与排版

### 2.1 字体族

| 用途 | 字体 | 说明 |
| --- | --- | --- |
| 品牌字 / 大标题 | `Noto Serif SC`（思源宋体）| 用于品牌名「珞珈BBS」、空状态标题、帖子详情阅读态标题，传递书卷气 |
| UI 正文 | `PingFang SC` → `HarmonyOS Sans SC` → `MiSans` → `system-ui` | 系统级无衬线，正文与组件 |
| 数字 / 英文 | `Inter` → `SF Pro` → `system-ui` | 计数、时间、ID |

> 规则：**宋体只出现在「品牌与编辑」时刻，正文一律无衬线**。宋体给高级感与书卷气，但大面积宋体会拖慢社区阅读节奏。

### 2.2 字号阶梯（Type Scale）

| Token | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| `display` | 28–34 | 600 | 1.2 | 品牌字、空状态主标题 |
| `title-1` | 24 | 600 | 1.3 | 页面主标题 |
| `title-2` | 20 | 600 | 1.35 | 区块标题、卡片组标题 |
| `title-3` | 17 | 600 | 1.4 | 帖子标题、列表项标题 |
| `body` | 15 | 400 | 1.6 | 正文 |
| `body-strong` | 15 | 500 | 1.6 | 正文强调 |
| `caption` | 13 | 400 | 1.5 | 辅助说明、时间、互动数据 |
| `caption-sm` | 12 | 400 | 1.5 | 标签、徽标、占位 |

> 小程序端最小字号不设低于 12，保证可读性。

## 3. 布局、间距、圆角、阴影

### 3.1 间距（8pt 栅格）

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-1` | 4 | 紧密元素 |
| `space-2` | 8 | 图标与文字间距 |
| `space-3` | 12 | 组件内 padding |
| `space-4` | 16 | 卡片内 padding |
| `space-5` | 24 | 区块间距 |
| `space-6` | 32 | 大区块 / 页面留白 |
| `space-7` | 48 | 页面顶部留白 |

### 3.2 圆角（Radius）

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-sm` | 8 | 标签、小徽标 |
| `radius-md` | 12 | 按钮、输入框 |
| `radius-lg` | 16 | 卡片、图片 |
| `radius-xl` | 24 | 浮层顶部、底部弹窗、Hero |

### 3.3 阴影与层次（Elevation）

阴影统一用**带绿意的暖影**，透明度低，营造「浮起但不沉重」的高级感。

| Token | 值 | 用途 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px rgba(24,32,27,.05)` | 卡片默认 |
| `shadow-md` | `0 4px 12px rgba(24,32,27,.06)` | 悬浮卡片、下拉 |
| `shadow-lg` | `0 12px 32px rgba(24,32,27,.10)` | 弹窗、浮层 |

### 3.4 图标

- 风格：**线性图标（2px 描边）**，圆角端点，风格统一。
- 尺寸：默认 20，标签内 16，强调场景 24。
- 颜色：默认 `ink-500`，激活/选中态 `green-500`，情绪态 `pink-500`。

## 4. 核心组件

### 4.1 按钮（Button）

| 类型 | 背景 | 文字 | 说明 |
| --- | --- | --- | --- |
| 主按钮 | `green-500` | 白 | 主要行动（发帖、登录、提交） |
| 次按钮 | `green-50` | `green-700` | 次要行动 |
| 幽灵按钮 | 透明 | `green-600` | 列表页轻量行动 |
| 危险按钮 | `error` | 白 | 删除、注销 |

- 高度：44（小程序触控友好）/ 40（Web）。
- 圆角：`radius-md`（12）。
- 状态：默认 → 按下（`green-600`）→ 禁用（`ink-400` 底 / 40% 透明度）。
- **主按钮加微弱阴影** `shadow-sm`，按下时阴影消失 + 轻微下移 1px，制造「按下去」的实感。

### 4.2 标签 / 徽标（Tag & Chip）

- **板块标签**（帖子上的 `出`/`求`/`教材` 等）：`green-100` 底 + `green-700` 字，`radius-sm`。必选标签（决定信息性质的 `出`/`求`/`租`）用 `green-500` 实心白字，视觉上「强」一级。
- **筛选标签**：选中态 `green-500` 底白字，未选 `surface-2` 底 `ink-500` 字。
- **状态徽标**：
  - 「精」精华：`gold-500` 底白字，小菱形或「精」字。
  - 「顶」置顶：`green-500` 描边 + `green-700` 字。
  - 「匿」匿名：`ink-400` 描边虚线 + `ink-500` 字，弱化处理。

### 4.3 认证徽标（「武大学生」）

- 样式：`gold-500` 填充的小盾形 / 对勾 + 「武大学生」四字，`caption-sm`。
- 位置：帖子作者名后、个人主页昵称后、回复楼层昵称后。
- 规则：**仅认证用户展示，未认证不占位**（不留空位，避免视觉噪音）。

### 4.4 帖子卡片（Post Card）

帖子列表的核心卡片，是「有序感」的主要载体。信息层级从上到下：

```
[状态徽标] 标题（title-3，最多 2 行，超出省略）
[标签 chips]
正文摘要（body，最多 2 行，ink-500，可选）
[图片九宫格（最多 3 张预览）]
作者 · 认证徽标 · 时间 · 浏览 · 回复 · 点赞（caption，右对齐）
```

- 卡片：`surface` 底，`radius-lg`（16），`shadow-sm`，内边距 `space-4`。
- **置顶帖**卡片顶部加一条 3px 的 `green-200` 细线；**精华帖**标题前加「精」金标。
- 卡片间距 `space-3`（12），页面左右留白 `space-4`（16）。

### 4.5 输入框（Input / 搜索）

- 搜索栏：`surface-2` 底，`radius-lg` 胶囊形，前置放大镜图标（`ink-400`），占位文字 `ink-400`。
- 输入框：`surface-2` 底，聚焦时描边 `green-500`（1.5px）+ 外圈 `green-50` 光晕。
- 发帖正文输入区：无边框大留白，弱化「表单感」，强化「写字感」。

### 4.6 底部导航栏（Tab Bar）

5 个入口：**首页（广场）· 板块 · 发帖（中央凸起）· 通知 · 我的**。

- 未选中：图标 + 文字 `ink-500`。
- 选中：图标 + 文字 `green-600`。
- **中央「发帖」做成凸起的圆形主按钮**（`green-500` 底 + 白色「+」），是全局唯一高饱和圆形按钮，一眼即「在这里发帖」。

### 4.7 空状态（Empty State）

- 结构：宋体主标题（`display`）+ 无衬线说明（`body`，`ink-500`）+ 一个主按钮。
- 插画：极简线性插画，主色 `green-300` + 点缀 `pink-300`，传递「温润、有人味」而非「空荡」。

### 4.8 提示（Toast / Snackbar）

- 成功：`green-600` 底白字 + 对勾。
- 错误：`error` 底白字。
- 中性：`ink-900` 底白字，圆角 `radius-md`，顶部或底部悬浮，2s 自动消失。

## 5. 关键页面

### 5.1 首页（广场）

自上而下：

1. **顶部**：品牌字「珞珈BBS」（宋体）＋ 搜索栏 ＋ 通知铃铛（带未读红点，红点用 `pink-500`）。
2. **分类入口**：5 大分类横向卡片（校园生活 / 学习成长 / 职业发展 / 社交娱乐 / 站务），每卡一个线性图标 + 分类名，`surface` 底。
3. **官方公告位**：一条 `green-50` 底的通栏公告条（站务公告置顶曝光）。
4. **精选内容流**：精选帖子卡片（含「精」金标），按质量+热度排序。
5. **热门讨论**：横向滚动的热度榜单卡。

> 首页不做信息瀑布（呼应 PRD F-05），靠留白与卡片层级营造「精选感」。

### 5.2 板块列表

1. **顶部**：板块名 + 说明，下方排序 Tab（综合 / 最新 / 最热 / 精华）。
2. **标签筛选**：横向滚动的筛选 chips（选中 `green-500`）。
3. **帖子列表**：置顶（细线标识）→ 精华（金标）→ 普通，三层清晰区分。
4. **右下角**：FAB「发帖」按钮（进入该板块发帖）。

### 5.3 帖子详情（含楼层）

1. **标题区**：宋体大标题 + 作者（昵称 + 鎏金徽标 + 时间）+ 正文 + 图片。
2. **互动条**：点赞（粉色激活）、收藏、举报。
3. **楼层区**：经典 BBS 楼层结构，每层左侧楼层号（`ink-400`），楼中楼缩进挂在父楼层下。
4. **底部**：固定在底部的回复输入栏 + 点赞/收藏快捷键。

> 阅读态是「内容沉淀」价值的核心场景，正文排版要宽松（`body` 15px、行高 1.6），让长文读得下去。

### 5.4 发帖流程

1. 选板块 → 选标签（必选/可选，chips 选择器）或填结构化字段（课程名/老师/学院 搜索补全）。
2. 标题输入 + 正文输入 + 多图上传（九宫格，每格「+」）。
3. 匿名开关（树洞/课程评价板块默认开启）。
4. 发布 → 若触发审核，toast 提示「内容已提交，审核通过后展示」。

### 5.5 个人中心（我的）

- 顶部：头像 + 昵称 + 鎏金认证徽标 + 学院/年级 + 签名。
- 数据概览：我的帖子 / 我的收藏 / 我的回复 三个入口卡片。
- 下方：设置、社区公约、举报反馈、退出登录。

### 5.6 登录

- 品牌字「珞珈BBS」居中 + 一句 slogan（宋体）。
- 邮箱输入 + 验证码输入（带「获取验证码」倒计时按钮）。
- 主按钮「登录」`green-500`。
- 底部：社区公约提示（注册即视为同意）。

## 6. 动效与微交互

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 按钮按压 | 120ms | `cubic-bezier(.2,0,0,1)` | 阴影消失 + 下移 1px |
| 页面转场 | 240ms | 同上 | 推入 + 轻微淡入 |
| 点赞激活 | 200ms | `cubic-bezier(.34,1.56,.64,1)` | 爱心放大回弹 + 变粉 |
| 列表加载 | 320ms | 同上 | 卡片淡入上移 8px |
| 骨架屏 | — | — | 用 `surface-2` 色块 + 呼吸透明度动画 |

- 原则：**动效服务于反馈与引导，不炫技**；一个页面同时动画不超过 2 处。

## 7. 双端适配（小程序 vs Web）

两端共享同一套 token 与组件语义，差异仅在**密度与输入方式**：

| 维度 | 微信小程序 | Web |
| --- | --- | --- |
| 触控目标 | ≥ 44px | ≥ 40px |
| 导航 | 底部 Tab Bar + 顶部胶囊 | 顶部导航 / 侧边栏（宽度 > 768 时） |
| 内容侧重 | 图片驱动（二手/树洞），卡片更图 | 长文驱动（经验帖/评价），正文更宽 |
| 发帖 | FAB 圆按钮 | 顶部「发帖」按钮 |
| 暗色 | 跟随系统 / 手动 | `prefers-color-scheme` + 手动切换 |
| 布局 | 单列，卡片流 | 单列（窄）→ 双列（宽） |

> 关键：**同一份设计 token（CSS/WXSS 变量）驱动两端**，避免两端视觉割裂（呼应 PRD 第 7 节「身份一致 / 双端对齐」）。

---

## 8. 无障碍与可用性

- **对比度**：正文 ≥ 4.5:1，大标题 ≥ 3:1（WCAG AA）。
- **触控目标**：≥ 44×44（小程序）、≥ 40×40（Web）。
- **色彩非唯一线索**：状态不只靠颜色区分，配合文字/图标（如「精」「顶」徽标）。
- **可读性**：最小字号 12，正文 15；行高不低于 1.5。
- **减少动效**：支持 `prefers-reduced-motion`，动画降级为淡入。
